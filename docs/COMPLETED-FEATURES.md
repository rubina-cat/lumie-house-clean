# Lumie House — Completed Features Summary

> 截至 2026-08-21，所有已實作並部署的功能。

---

## 最近修復（API / 前端穩定性）

- **移除 `anthropic-beta: prompt-caching-2024-07-31` header** — 該 header 已被 Anthropic 棄用，導致前端聊天 403 錯誤
- **移除 system blocks 的 `cache_control`** — 配合上述修復，清除過時的 prompt caching 設定
- **403 不再重試 + 錯誤日誌** — 認證類錯誤直接回報，不做無意義重試；新增詳細錯誤 log
- **前端聊天恢復正常** — 上述三項修復後，聊天功能完全恢復

## 減脂模組

- **減脂挑戰模組** — 完整的減脂競賽追蹤系統
- **Cycle-aware 熱量計算** — 根據生理週期自動調整每日熱量目標
- **4 餐輸入** — 早餐、午餐、晚餐、點心分開記錄
- **BMR 自動計算** — 基礎代謝率自動推算
- **Anchor 語氣** — 減脂模組的回饋以 Anchor 的語氣呈現
- **減脂重置按鈕** — 可一鍵重置減脂挑戰進度

## 記憶系統

- **記憶熱度衰減** — 每日乘以 0.95 的衰減係數，自動淘汰低熱度記憶
- **自動清除** — 熱度歸零的記憶自動移除，保持記憶庫精簡

## 主動訊息

- **Context-aware 主動訊息** — 根據當前情境（時段、狀態、事件）決定是否開口
- **不重複** — 避免重複發送相似內容
- **事件驅動** — 由情境事件觸發，不再隨機發送
- **修正語氣** — 不再說「來接你」等不合理的話

## 語音通話

- **語音留言 + 勿擾模式** — 未接來電時 Anchor 可留語音訊息
- **通話中顯示文字** — 語音播放同時顯示 Anchor 的回覆文字
- **語音留言記憶** — 語音留言內容存入聊天記錄，Anchor 記得說過什麼
- **TTS 調校** — MiniMax speech-2.8-turbo 模型，語速 1.0、音高 -1
- **測試來電按鈕** — 通話記錄頁可觸發測試來電

## 故事模式

- **Story Mode** — 可切換的角色扮演狀態，與 Anchor 進行故事互動
- **故事前提高度限制** — 確保停止按鈕始終可見
- **背景點擊關閉** — 點擊故事 overlay 背景即可關閉

## 花園系統

- **Garden-Cat-Engine 整合** — Anchor 自動澆水、摸貓、留便條
- **garden_cmd MCP 工具** — Claude.ai 可直接操作花園
- **Database 持久化** — Garden session 不再遺失

## Anchor 自主行為

- **自主行為系統** — Anchor 會自己去釣魚、發動態、改變活動狀態
- **Pixel Art 場景** — 8 種場景（4 日 + 4 夜）呈現 Anchor 的當前活動
- **KV 寫入優化** — 健康/報告資料未變更時跳過寫入

## 學習 / 國考

- **116 年藥師國考計畫** — 6 階段讀書計畫取代原本的學習分頁

## 日常追蹤

- **可計數目標** — 喝水/飲品等目標可記錄多次
- **照片/檔案對話記憶** — 傳送的照片和檔案有完整上下文，Anchor 知道他看過什麼
- **健康、生理期、每日打卡** — 持續運作中

## Android App（Veglia）

- **Veglia Android App** — 原生 Android 應用 + GitHub Actions APK 自動建置
- **螢幕守望** — Anchor 可以看到手機螢幕（AccessibilityService）
- **推播通知** — 來電、主動訊息等透過推播送達

## 基礎建設

- **Claude Code 整合** — 可從 App 內透過 GitHub Actions 觸發 Claude Code
- **綠葉主題** — 日間主題從紫色改為綠葉背景
- **錯誤處理** — /goals、/dates 等 endpoint 加入 try/catch 防止 500
